## 二、N-gram：统计语言模型

### 2.1 什么是语言模型？

语言模型（Language Model，LM）的核心任务之一：

**预测一个词序列出现的概率，或根据前面的词预测下一个词。**

例如：

```text
输入：我 今天 想 学习
预测：Python
```

语言模型需要计算：

$$
P(w_t \mid w_1,w_2,\ldots,w_{t-1})
$$

即：已知前面的词，预测下一个词的概率。

### 2.2 什么是 N-gram？

N-gram 假设预测当前词时，只需要考虑前面有限数量的词。

**Bigram（二元模型）：**

$$
P(w_t \mid w_{t-1})
$$

**Trigram（三元模型）：**

$$
P(w_t \mid w_{t-2},w_{t-1})
$$

一般形式：

$$
P(w_t\mid w_{t-N+1},\ldots,w_{t-1})
$$

以 Bigram 为例，可以使用词频估计概率：

$$
P(w_t\mid w_{t-1})
\approx
\frac{C(w_{t-1},w_t)}{C(w_{t-1})}
$$

其中：

- $C(w_{t-1},w_t)$：两个词连续出现的次数。
- $C(w_{t-1})$：前一个词出现的次数。

### 2.3 N-gram 的问题

1. 数据稀疏：未出现过的词语组合难以估计概率。
2. 上下文有限：通常只能考虑固定长度的历史信息。
3. 参数规模大：随着 N 增大，可能的词语组合急剧增加。
4. 泛化能力有限：不能直接利用词语之间的语义相似性。

## 三、Word Embedding：词向量

### 3.1 为什么需要词向量？

计算机不能直接对自然语言词语进行神经网络数值计算。

因此需要把词转换成数字表示。

传统 One-hot 编码：

```text
苹果 = [1, 0, 0, 0]
香蕉 = [0, 1, 0, 0]
汽车 = [0, 0, 1, 0]
电脑 = [0, 0, 0, 1]
```

问题：

- 向量通常非常稀疏。
- 维度与词表大小相同。
- 不直接表达词语之间的语义关系。

### 3.2 Embedding 的思想

使用一个可学习的向量表示每个词或 Token。

例如：

```text
苹果 → [0.21, 0.83, -0.15, ...]
香蕉 → [0.25, 0.79, -0.12, ...]
汽车 → [-0.71, 0.12, 0.64, ...]
```

上面的数值仅用于说明。

经过合适的训练，语义或使用环境相近的词可能具有相近的向量表示。

### 3.3 Embedding 的数学形式

设：

- $V$：词表大小。
- $d$：Embedding 维度。

Embedding 矩阵为：

$$
E\in\mathbb{R}^{V\times d}
$$

假设：

$$
V=50000,\quad d=768
$$

那么：

$$
E\in\mathbb{R}^{50000\times768}
$$

输入一个 Token ID，就可以从 Embedding 矩阵中查找对应的向量。

### 3.4 相似度计算

常见方法是余弦相似度：

$$
\operatorname{cos}(A,B)
=
\frac{A\cdot B}{\|A\|\|B\|}
$$

用于衡量两个向量方向上的相似程度。

### 3.5 与 Transformer 的关系

Transformer 处理文本的一般起点：

```text
原始文本
   ↓
Tokenizer
   ↓
Token IDs
   ↓
Embedding
   ↓
向量序列
   ↓
Transformer Blocks
```

需要区分：

- Tokenization：把文本拆分并转换为 Token ID。
- Embedding：把 Token ID 映射为可学习的向量。
- Hidden State：模型中间层产生的上下文表示。

## 四、FFN：前馈神经网络

### 4.1 什么是神经网络？

神经网络可以看作由多个可学习的数学变换组成的函数。

最简单的线性层：

$$
y=Wx+b
$$

其中：

- $x$：输入向量。
- $W$：权重矩阵。
- $b$：偏置。
- $y$：输出向量。

加入激活函数：

$$
y=f(Wx+b)
$$

其中 $f$ 可以是 ReLU、GELU 等。

### 4.2 为什么需要激活函数？

如果网络只包含多个线性变换：

$$
y=W_2(W_1x)
$$

那么：

$$
y=(W_2W_1)x
$$

多个线性层仍然可以合并为一个线性变换。

因此，需要非线性激活函数来提高表达能力。

常见 ReLU：

$$
\operatorname{ReLU}(x)=\max(0,x)
$$

### 4.3 两层 FFN

Transformer 中常见的基础 FFN 形式：

$$
\operatorname{FFN}(x)
=
W_2\sigma(W_1x+b_1)+b_2
$$

其中：

- 第一层通常将维度扩大。
- 激活函数引入非线性。
- 第二层将维度映射回模型隐藏维度。

例如：

```text
输入维度：768
     ↓
Linear
     ↓
中间维度：3072
     ↓
GELU
     ↓
Linear
     ↓
输出维度：768
```

这是经典 Transformer FFN 的示意，不代表所有现代模型都使用相同结构。

现代大模型中还常见 SwiGLU 等门控 FFN 变体。

## 五、RNN：循环神经网络

### 5.1 FFN 为什么不够？

普通 FFN 本身不会自动记住之前的输入。

例如：

```text
我 → 今天 → 学习 → Python
```

语言有顺序关系，后面的词往往需要结合前面的内容进行理解。

RNN 为此引入隐藏状态。

### 5.2 RNN 的核心结构

```text
x1 ──► RNN ──► h1
                 │
x2 ──► RNN ──► h2
                 │
x3 ──► RNN ──► h3
                 │
x4 ──► RNN ──► h4
```

其中：

- $x_t$：当前时间步输入。
- $h_t$：当前隐藏状态。
- $h_{t-1}$：上一个时间步的隐藏状态。

经典简单 RNN 的计算：

$$
h_t=
\tanh(W_xx_t+W_hh_{t-1}+b)
$$

**核心思想：当前状态由当前输入和历史状态共同决定。**

### 5.3 RNN 的优势

1. 可以处理变长序列。
2. 能通过隐藏状态传递历史信息。
3. 不同时间步共享网络参数。

### 5.4 RNN 的局限

**问题一：长距离依赖**

当两个相关词距离很远时，模型不容易保留早期信息。

**问题二：梯度消失或爆炸**

训练时需要沿时间方向反向传播梯度。

当序列很长时，连续的梯度运算可能导致梯度过小或过大。

**问题三：串行计算**

计算 $h_t$ 通常依赖 $h_{t-1}$。

因此不同时间步之间难以完全并行计算。

### 5.5 学习重点

- [ ] 理解隐藏状态。
- [ ] 理解时间步。
- [ ] 理解参数共享。
- [ ] 理解梯度消失和梯度爆炸。
- [ ] 理解为什么 RNN 存在串行依赖。

## 六、LSTM：长短期记忆网络

### 6.1 为什么出现 LSTM？

普通 RNN 不容易学习长期依赖关系。

LSTM（Long Short-Term Memory）通过门控结构改善信息保留和梯度传播。

### 6.2 LSTM 的核心思想

可以把 LSTM 理解成具有信息管理机制的 RNN。

它使用：

- Forget Gate：遗忘门。
- Input Gate：输入门。
- Output Gate：输出门。
- Cell State：细胞状态。

### 6.3 三种门的作用

#### 遗忘门

决定旧信息保留多少。

$$
f_t=\sigma(W_f[h_{t-1},x_t]+b_f)
$$

#### 输入门

决定当前新信息写入多少。

$$
i_t=\sigma(W_i[h_{t-1},x_t]+b_i)
$$

#### 输出门

决定从内部状态输出哪些信息。

$$
o_t=\sigma(W_o[h_{t-1},x_t]+b_o)
$$

其中：

$$
\sigma(x)=\frac{1}{1+e^{-x}}
$$

Sigmoid 将数值映射到 $(0,1)$ 区间。

### 6.4 LSTM 解决了什么？

LSTM 通过细胞状态与门控机制，改善了普通 RNN 学习长期依赖的能力。

但并不意味着 LSTM 能无限记忆所有历史信息。

### 6.5 LSTM 仍然有什么问题？

LSTM 通常仍需要按时间步依次更新状态。

因此：

- 难以充分利用序列维度上的并行计算。
- 处理长序列时存在较长的顺序依赖链。
- 长距离依赖问题得到缓解，但没有彻底消失。

### 6.6 学习重点

- [ ] 理解 LSTM 为什么出现。
- [ ] 理解三个门的作用。
- [ ] 理解 Hidden State 与 Cell State。
- [ ] 知道 LSTM 为什么仍然存在串行计算瓶颈。

**重要程度：★★☆☆☆**

## 七、Attention：注意力机制

### 7.1 为什么需要 Attention？

假设有一句话：

> 小明把书放到桌子上，因为它太重了。

模型理解“它”指代什么时，需要结合句子中的其他词。

Attention 的思想：

**处理一个位置的信息时，根据相关性选择性地利用其他位置的信息。**

### 7.2 Q、K、V

Attention 使用三个核心向量：

- Query（Q）：当前需要查找什么信息？
- Key（K）：每个位置提供什么匹配线索？
- Value（V）：每个位置实际提供什么信息？

通过 Query 和 Key 计算匹配程度。

再根据匹配权重，对 Value 进行加权求和。

### 7.3 核心计算公式

Scaled Dot-Product Attention：

$$
\operatorname{Attention}(Q,K,V)
=
\operatorname{softmax}
\left(
\frac{QK^T}{\sqrt{d_k}}
\right)V
$$

可以分成四步：

**第一步：计算相关性分数**

$$
S=QK^T
$$

**第二步：缩放分数**

$$
S'=\frac{S}{\sqrt{d_k}}
$$

**第三步：Softmax 归一化**

$$
A=\operatorname{softmax}(S')
$$

**第四步：对 Value 加权求和**

$$
O=AV
$$

其中：

- $A$：注意力权重。
- $O$：Attention 输出。

### 7.4 什么是 Self-Attention？

Self-Attention（自注意力）：

Q、K、V 都来自同一个输入序列的表示。

例如：

```text
输入 Token：
[我, 喜欢, 学习, Python]

            ↓
       Self-Attention
            ↓

每个 Token 根据其他 Token
的信息更新自己的表示
```

### 7.5 什么是 Multi-Head Attention？

Multi-Head Attention（多头注意力）：

通过多个注意力头，在不同的表示子空间中学习关联关系。

不同注意力头可能关注不同类型的信息关系，但不能简单认为每个头都固定对应某一种语法或语义功能。

### 7.6 Attention 的工程问题

标准全注意力中，如果序列长度为 $n$：

注意力分数矩阵形状为：

$$
n\times n
$$

其元素数量为：

$$
n^2
$$

因此，长序列下标准注意力存在较高的计算与显存开销。

这也是后续学习以下技术的重要基础：

- FlashAttention
- KV Cache
- 长序列优化
- Attention 并行计算

## 八、Transformer：将前置知识串联起来

### 8.1 Transformer 的核心思想

Transformer 不再依赖 RNN 式的循环结构作为主要序列建模方式。

它主要使用注意力机制建立 Token 之间的联系，并结合前馈网络等模块完成特征变换。

### 8.2 Transformer Block

经典 Transformer Block 的主要组成：

```text
输入 Hidden States
        │
        ▼
Multi-Head Attention
        │
        ▼
Residual + LayerNorm
        │
        ▼
Feed Forward Network
        │
        ▼
Residual + LayerNorm
        │
        ▼
输出 Hidden States
```

注：这是经典 Post-LN 架构的简化示意。现代 GPT/LLaMA 类模型常采用 Pre-Norm、RMSNorm、门控 FFN 等变体。

### 8.3 Transformer 与前置知识的联系

| 前置知识  | 在 Transformer 中的作用               |
| --------- | ------------------------------------- |
| N-gram    | 理解语言模型与预测下一个 Token 的任务 |
| Embedding | 将 Token ID 转换为向量表示            |
| FFN       | 对 Token 表示进行非线性特征变换       |
| RNN       | 帮助理解历史序列建模方式及其局限      |
| LSTM      | 帮助理解长距离依赖和串行计算问题      |
| Attention | Transformer 的核心序列交互机制        |

### 8.4 为什么 Transformer 更适合大模型训练？

主要原因：

1. 能直接建模不同 Token 之间的关联。
2. 训练阶段的注意力计算适合矩阵化和大规模并行。
3. 更容易扩展到较大的模型规模和数据规模。
4. 能有效利用 GPU、NPU 等加速硬件。

注意：自回归大模型在推理生成阶段，仍然需要逐步生成新的 Token。

因此，训练并行能力与推理阶段的串行生成特性需要分开理解。

    └── Feed Forward Network（前馈神经网络）
            学习输入与输出之间的非线性关系
    │
    ▼
RNN（循环神经网络）
    │  引入隐藏状态，处理变长序列
    │  局限：长距离依赖、梯度消失
    ▼
LSTM（长短期记忆网络）
    │  引入门控机制，改善长期信息保留
    │  局限：仍然需要时间步串行计算
    ▼
Attention（注意力机制）
    │  根据相关性动态关注不同位置的信息
    ▼
Transformer
    │  以自注意力为核心，摆脱循环结构
    ▼
GPT / LLaMA / DeepSeek 等大语言模型
```

注意：

- 以上是一条帮助理解的技术演进路线，并非严格的发明时间顺序。
- Embedding 和 FFN 并没有被淘汰，它们仍然广泛用于 Transformer。
- Attention 最初也被用于 RNN 编码器—解码器结构。

## 二、N-gram：统计语言模型

### 2.1 什么是语言模型？

语言模型（Language Model，LM）的核心任务之一：

**预测一个词序列出现的概率，或根据前面的词预测下一个词。**

例如：

```text
输入：我 今天 想 学习
预测：Python
```

语言模型需要计算：

$$
P(w_t \mid w_1,w_2,\ldots,w_{t-1})
$$

即：已知前面的词，预测下一个词的概率。

### 2.2 什么是 N-gram？

N-gram 假设预测当前词时，只需要考虑前面有限数量的词。

**Bigram（二元模型）：**

$$
P(w_t \mid w_{t-1})
$$

**Trigram（三元模型）：**

$$
P(w_t \mid w_{t-2},w_{t-1})
$$

一般形式：

$$
P(w_t\mid w_{t-N+1},\ldots,w_{t-1})
$$

以 Bigram 为例，可以使用词频估计概率：

$$
P(w_t\mid w_{t-1})
\approx
\frac{C(w_{t-1},w_t)}{C(w_{t-1})}
$$

其中：

- $C(w_{t-1},w_t)$：两个词连续出现的次数。
- $C(w_{t-1})$：前一个词出现的次数。

### 2.3 N-gram 的问题

1. 数据稀疏：未出现过的词语组合难以估计概率。
2. 上下文有限：通常只能考虑固定长度的历史信息。
3. 参数规模大：随着 N 增大，可能的词语组合急剧增加。
4. 泛化能力有限：不能直接利用词语之间的语义相似性。

### 2.4 学习重点

- [ ] 理解条件概率。
- [ ] 理解语言模型预测下一个词的思想。
- [ ] 理解 N-gram 的局限。
- [ ] 知道数据稀疏和平滑的含义。

**本阶段不需要：** 深入学习各种 N-gram 平滑算法。

## 三、Word Embedding：词向量

### 3.1 为什么需要词向量？

计算机不能直接对自然语言词语进行神经网络数值计算。

因此需要把词转换成数字表示。

传统 One-hot 编码：

```text
苹果 = [1, 0, 0, 0]
香蕉 = [0, 1, 0, 0]
汽车 = [0, 0, 1, 0]
电脑 = [0, 0, 0, 1]
```

问题：

- 向量通常非常稀疏。
- 维度与词表大小相同。
- 不直接表达词语之间的语义关系。

### 3.2 Embedding 的思想

使用一个可学习的向量表示每个词或 Token。

例如：

```text
苹果 → [0.21, 0.83, -0.15, ...]
香蕉 → [0.25, 0.79, -0.12, ...]
汽车 → [-0.71, 0.12, 0.64, ...]
```

上面的数值仅用于说明。

经过合适的训练，语义或使用环境相近的词可能具有相近的向量表示。

### 3.3 Embedding 的数学形式

设：

- $V$：词表大小。
- $d$：Embedding 维度。

Embedding 矩阵为：

$$
E\in\mathbb{R}^{V\times d}
$$

假设：

$$
V=50000,\quad d=768
$$

那么：

$$
E\in\mathbb{R}^{50000\times768}
$$

输入一个 Token ID，就可以从 Embedding 矩阵中查找对应的向量。

### 3.4 相似度计算

常见方法是余弦相似度：

$$
\operatorname{cos}(A,B)
=
\frac{A\cdot B}{\|A\|\|B\|}
$$

用于衡量两个向量方向上的相似程度。

### 3.5 与 Transformer 的关系

Transformer 处理文本的一般起点：

```text
原始文本
   ↓
Tokenizer
   ↓
Token IDs
   ↓
Embedding
   ↓
向量序列
   ↓
Transformer Blocks
```

需要区分：

- Tokenization：把文本拆分并转换为 Token ID。
- Embedding：把 Token ID 映射为可学习的向量。
- Hidden State：模型中间层产生的上下文表示。

### 3.6 学习重点

- [ ] 理解 One-hot 与 Embedding 的区别。
- [ ] 理解词表大小和 Embedding 维度。
- [ ] 理解 Embedding 矩阵查表。
- [ ] 理解 Token、Token ID、Embedding 的关系。
- [ ] 了解 Word2Vec 的基本思想。

**重要程度：★★★★★**

## 四、FFN：前馈神经网络

### 4.1 什么是神经网络？

神经网络可以看作由多个可学习的数学变换组成的函数。

最简单的线性层：

$$
y=Wx+b
$$

其中：

- $x$：输入向量。
- $W$：权重矩阵。
- $b$：偏置。
- $y$：输出向量。

加入激活函数：

$$
y=f(Wx+b)
$$

其中 $f$ 可以是 ReLU、GELU 等。

### 4.2 为什么需要激活函数？

如果网络只包含多个线性变换：

$$
y=W_2(W_1x)
$$

那么：

$$
y=(W_2W_1)x
$$

多个线性层仍然可以合并为一个线性变换。

因此，需要非线性激活函数来提高表达能力。

常见 ReLU：

$$
\operatorname{ReLU}(x)=\max(0,x)
$$

### 4.3 两层 FFN

Transformer 中常见的基础 FFN 形式：

$$
\operatorname{FFN}(x)
=
W_2\sigma(W_1x+b_1)+b_2
$$

其中：

- 第一层通常将维度扩大。
- 激活函数引入非线性。
- 第二层将维度映射回模型隐藏维度。

例如：

```text
输入维度：768
     ↓
Linear
     ↓
中间维度：3072
     ↓
GELU
     ↓
Linear
     ↓
输出维度：768
```

这是经典 Transformer FFN 的示意，不代表所有现代模型都使用相同结构。

现代大模型中还常见 SwiGLU 等门控 FFN 变体。

### 4.4 学习重点

- [ ] 理解权重与偏置。
- [ ] 理解矩阵乘法。
- [ ] 理解激活函数。
- [ ] 理解输入维度与输出维度。
- [ ] 了解反向传播与梯度下降。
- [ ] 知道 FFN 是 Transformer Block 的重要组成部分。

**重要程度：★★★★★**

## 五、RNN：循环神经网络

### 5.1 FFN 为什么不够？

普通 FFN 本身不会自动记住之前的输入。

例如：

```text
我 → 今天 → 学习 → Python
```

语言有顺序关系，后面的词往往需要结合前面的内容进行理解。

RNN 为此引入隐藏状态。

### 5.2 RNN 的核心结构

```text
x1 ──► RNN ──► h1
                 │
x2 ──► RNN ──► h2
                 │
x3 ──► RNN ──► h3
                 │
x4 ──► RNN ──► h4
```

其中：

- $x_t$：当前时间步输入。
- $h_t$：当前隐藏状态。
- $h_{t-1}$：上一个时间步的隐藏状态。

经典简单 RNN 的计算：

$$
h_t=
\tanh(W_xx_t+W_hh_{t-1}+b)
$$

**核心思想：当前状态由当前输入和历史状态共同决定。**

### 5.3 RNN 的优势

1. 可以处理变长序列。
2. 能通过隐藏状态传递历史信息。
3. 不同时间步共享网络参数。

### 5.4 RNN 的局限

**问题一：长距离依赖**

当两个相关词距离很远时，模型不容易保留早期信息。

**问题二：梯度消失或爆炸**

训练时需要沿时间方向反向传播梯度。

当序列很长时，连续的梯度运算可能导致梯度过小或过大。

**问题三：串行计算**

计算 $h_t$ 通常依赖 $h_{t-1}$。

因此不同时间步之间难以完全并行计算。

### 5.5 学习重点

- [ ] 理解隐藏状态。
- [ ] 理解时间步。
- [ ] 理解参数共享。
- [ ] 理解梯度消失和梯度爆炸。
- [ ] 理解为什么 RNN 存在串行依赖。

**重要程度：★★★☆☆**

## 六、LSTM：长短期记忆网络

### 6.1 为什么出现 LSTM？

普通 RNN 不容易学习长期依赖关系。

LSTM（Long Short-Term Memory）通过门控结构改善信息保留和梯度传播。

### 6.2 LSTM 的核心思想

可以把 LSTM 理解成具有信息管理机制的 RNN。

它使用：

- Forget Gate：遗忘门。
- Input Gate：输入门。
- Output Gate：输出门。
- Cell State：细胞状态。

### 6.3 三种门的作用

#### 遗忘门

决定旧信息保留多少。

$$
f_t=\sigma(W_f[h_{t-1},x_t]+b_f)
$$

#### 输入门

决定当前新信息写入多少。

$$
i_t=\sigma(W_i[h_{t-1},x_t]+b_i)
$$

#### 输出门

决定从内部状态输出哪些信息。

$$
o_t=\sigma(W_o[h_{t-1},x_t]+b_o)
$$

其中：

$$
\sigma(x)=\frac{1}{1+e^{-x}}
$$

Sigmoid 将数值映射到 $(0,1)$ 区间。

### 6.4 LSTM 解决了什么？

LSTM 通过细胞状态与门控机制，改善了普通 RNN 学习长期依赖的能力。

但并不意味着 LSTM 能无限记忆所有历史信息。

### 6.5 LSTM 仍然有什么问题？

LSTM 通常仍需要按时间步依次更新状态。

因此：

- 难以充分利用序列维度上的并行计算。
- 处理长序列时存在较长的顺序依赖链。
- 长距离依赖问题得到缓解，但没有彻底消失。

### 6.6 学习重点

- [ ] 理解 LSTM 为什么出现。
- [ ] 理解三个门的作用。
- [ ] 理解 Hidden State 与 Cell State。
- [ ] 知道 LSTM 为什么仍然存在串行计算瓶颈。

**重要程度：★★☆☆☆**

现阶段不需要手写 LSTM，也不需要死记所有门控公式。

## 七、Attention：注意力机制

### 7.1 为什么需要 Attention？

假设有一句话：

> 小明把书放到桌子上，因为它太重了。

模型理解“它”指代什么时，需要结合句子中的其他词。

Attention 的思想：

**处理一个位置的信息时，根据相关性选择性地利用其他位置的信息。**

### 7.2 Q、K、V

Attention 使用三个核心向量：

- Query（Q）：当前需要查找什么信息？
- Key（K）：每个位置提供什么匹配线索？
- Value（V）：每个位置实际提供什么信息？

通过 Query 和 Key 计算匹配程度。

再根据匹配权重，对 Value 进行加权求和。

### 7.3 核心计算公式

Scaled Dot-Product Attention：

$$
\operatorname{Attention}(Q,K,V)
=
\operatorname{softmax}
\left(
\frac{QK^T}{\sqrt{d_k}}
\right)V
$$

可以分成四步：

**第一步：计算相关性分数**

$$
S=QK^T
$$

**第二步：缩放分数**

$$
S'=\frac{S}{\sqrt{d_k}}
$$

**第三步：Softmax 归一化**

$$
A=\operatorname{softmax}(S')
$$

**第四步：对 Value 加权求和**

$$
O=AV
$$

其中：

- $A$：注意力权重。
- $O$：Attention 输出。

### 7.4 什么是 Self-Attention？

Self-Attention（自注意力）：

Q、K、V 都来自同一个输入序列的表示。

例如：

```text
输入 Token：
[我, 喜欢, 学习, Python]

            ↓
       Self-Attention
            ↓

每个 Token 根据其他 Token
的信息更新自己的表示
```

### 7.5 什么是 Multi-Head Attention？

Multi-Head Attention（多头注意力）：

通过多个注意力头，在不同的表示子空间中学习关联关系。

不同注意力头可能关注不同类型的信息关系，但不能简单认为每个头都固定对应某一种语法或语义功能。

### 7.6 Attention 的工程问题

标准全注意力中，如果序列长度为 $n$：

注意力分数矩阵形状为：

$$
n\times n
$$

其元素数量为：

$$
n^2
$$

因此，长序列下标准注意力存在较高的计算与显存开销。

这也是后续学习以下技术的重要基础：

- FlashAttention
- KV Cache
- 长序列优化
- Attention 并行计算

### 7.7 学习重点

- [ ] 理解 Attention 的核心动机。
- [ ] 理解 Q、K、V。
- [ ] 理解 Softmax。
- [ ] 理解矩阵乘法与转置。
- [ ] 理解 Self-Attention。
- [ ] 理解 Multi-Head Attention。
- [ ] 理解序列长度对计算和显存的影响。

**重要程度：★★★★★**

## 八、Transformer：将前置知识串联起来

### 8.1 Transformer 的核心思想

Transformer 不再依赖 RNN 式的循环结构作为主要序列建模方式。

它主要使用注意力机制建立 Token 之间的联系，并结合前馈网络等模块完成特征变换。

### 8.2 Transformer Block

经典 Transformer Block 的主要组成：

```text
输入 Hidden States
        │
        ▼
Multi-Head Attention
        │
        ▼
Residual + LayerNorm
        │
        ▼
Feed Forward Network
        │
        ▼
Residual + LayerNorm
        │
        ▼
输出 Hidden States
```

注：这是经典 Post-LN 架构的简化示意。现代 GPT/LLaMA 类模型常采用 Pre-Norm、RMSNorm、门控 FFN 等变体。

### 8.3 Transformer 与前置知识的联系

| 前置知识  | 在 Transformer 中的作用               |
| --------- | ------------------------------------- |
| N-gram    | 理解语言模型与预测下一个 Token 的任务 |
| Embedding | 将 Token ID 转换为向量表示            |
| FFN       | 对 Token 表示进行非线性特征变换       |
| RNN       | 帮助理解历史序列建模方式及其局限      |
| LSTM      | 帮助理解长距离依赖和串行计算问题      |
| Attention | Transformer 的核心序列交互机制        |

### 8.4 为什么 Transformer 更适合大模型训练？

主要原因：

1. 能直接建模不同 Token 之间的关联。
2. 训练阶段的注意力计算适合矩阵化和大规模并行。
3. 更容易扩展到较大的模型规模和数据规模。
4. 能有效利用 GPU、NPU 等加速硬件。

注意：自回归大模型在推理生成阶段，仍然需要逐步生成新的 Token。

因此，训练并行能力与推理阶段的串行生成特性需要分开理解。
