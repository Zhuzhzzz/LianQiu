## 编码器

序列模型 现在比较好的是一个编码器解码器的架构

编码器：原始输入到机器学习可以裂解的一系列的向量 解码器：自回归 一个个的生成（不一定跟编码器产生的一样长）过去时刻的输出也会作为你当前时刻的输入

Transformer的架构图 编码器 解码器架构

输入 -> embedding 变成向量 然后进入n层 。 Transformer Block 残差的连接 前馈神经网络之类。 然后编码器的输出就会作为一个解码器的输入 linear softmax 输出

Encoder N =  6层 每个layer里面会有两个sub-layers 子层 多头注意力  MLP（多层感知层）对每一个子层使用了一个残差连接(找时间补习了解一下）最后再使用一个layer normalization的东西 子层公式LayerNorm(x + Sublayer(x)) 残差连接 输入输出加在一起（回头理一下这个细节）残差需要输入输出一样大小 为了简单起见 把每一个层的输出的维度变成512（跟CNN不一样 MLP经常把维度要么往下减）这里固定长度来表示（ps如何理解维度）使得模型相对来说比较简单调参也就调一个参就行了，另一个参数就是复制多少块(N)。这个简单设计影响到后面一系列网络 bert GPT

Layernorm 对比 batchnorm 为什么我们在这些变长的应用里面不使用batchnorm（批量归一化）
batchnorm 考虑最简单的二维输入情况 输入一个矩阵 每一行一个样本 每一列是一个特征feature batchnorm干的事情 每一次 把每一个列每一个特征 在一个小 mini-batch里面 均值变成零 方差变成1 （把这个向量本身的均值减掉 除以方差）（训练是小批量的标准化，预测是全局标准化）layernorm 是对每一个样本行 变成均值0方差1 （可以认为layernorm就是把整个数据转置一下放到batchnorm里面出来的结果再转置一下出来的东西）这个是输入是二维的时候最简单的情况 但是在Transformer里面或者正常的RNN里面输入是一个三维的东西 因为输入的是一个序列的样本 每一个样本里面有很多元素 是一个序列 一个句子里有n个词（每一行是同一个样本的不同特征， 每一列是不同样本的一个特征） 每一个词有一个向量 还有一个batch的话就是一个3D的东西（没理解。）
三维：行（）batch 样本 列不再是特征而是序列的长度sequence 然后对每一个sequence就是对每个词当然有自自己的向量（额外一个维度变成立体的了feature）Transformer里面seq长为n feat为d刚刚设成了512 对于这个方体 两种方式的切法不一样。

具体讲为什么layernorm用的多。一个原因是持续的这些序列模型里面，你的每个样本的长度可能会发生变化（每一行可能长度不一样，没有的一般放0）layernorm会好用的原因（*没听懂，数学功力差点）

## 解码器

解码器跟编码器很像，是由N = 6 个同样的层构成的 也有两个一样的子层。不一样的地方在于decoder用了一个第三个子层，多头的注意力机制，同样用了残差连接，用了layernorm。解码器的时候做的是一个自回归，当前的输出的输入集是上面一些时刻的输出，意味着在做预测的时候你当然不能看到之后的那些时刻的输出。在注意力机制里面他每一次能看到整个的完整的输入。所以通过一个带掩码的注意力机制Masked，保证输入进来t时间是不会看到t时间之后的输出。从而保证训练和预测的时候行为一直

## 注意力层

原文解释，注意力函数是一个将一个query 和一些 key-value对 映射成一个输出的一个函数query key value output 都是向量output是你的value的一个加权和输出的维度和value的维度是一样的。权重是怎么来的，对于每一个value的权重是这个value对应的key 和 查询的这个query的相似度算来的。相似度，不同的注意力机制有不同的算法。随着q的变化，相同的kv导致权重的分配不一样，导致输出会有不一样，这就是注意力机制。因为不同的相似函数导致不一样的注意力的版本。

### Scaled Dot-Product Attention

讲的是Transformer提出的这一个注意力。实际上是最简单的注意力机制，query 和 key的长度是等长的dk value是dv（那么输出也一样的是dv）具体计算是说对每一个query和key做内积，作为相似度。再除以√dk（向量的长度）再用一个softmax来得到权重。

给一个query，假设给n个key value pair的话，那就会算出n个值。因为这个query会跟每个key做内积。算出来之后放进softmax就会得到n个非负的，而且加起来和等于一的一个权重。把权重作用在value上面，就会得到我们的输出了。实际上不能这样一个一个做运算，会比较慢。

Query可以写成一个矩阵matrix。可能不止一个query，比如n个query。n行维度dk。 query的个数和keyvalue个数可能不一样，但是长度是一样的dk，这样才能做内积。k m个，内积得到n * m的矩阵。那么这个矩阵每一行都是q v内积值。然后除以√dk 再做softmax得到权重，再乘上v。那么v是m行（跟k一样）列数dv的矩阵。然后相乘得到一个n乘dv的矩阵。每一行就是我们要的一个输出。这里可以看到对于一组key value对，和n个query的话，可以通过两次矩阵乘法，来做掉。这些query value key 在实际中对应的就是我序列。这样可以基本上并行的计算里面的每个元素，因为矩阵乘法是一个非常好并行的东西。

下面介绍提出的注意力机制跟别的区别是什么样子的，一种叫做加型的注意力机制，可以处理key value不等长的情况，另一种叫做点积的注意力机制（跟提出的差不多）。但是他选用的是点乘，实现起来比较简单，比较高效，两次矩阵乘法。

需要解释一下，为什么不直接用最简单的点乘注意力。为什么要除以√dk。当dk不是很大的时候，除不除都没关系，当dk比较大的时候，两个向量，长度比较长的时候，做点积的时候值可能会比较大，也可能比较小，导致相对的差距会变大，最大的值做出来softmax会更加靠近于1，剩下的值会更加靠近于0，会向两端靠拢。算梯度的时候（梯度不是很理解）。softmax最后的结果，我希望我的预测值，置信的地方靠近于1不置信的地方尽量靠近0，收敛差不多了，梯度比较小，会跑不动（理解为不能太快收敛？）。Transformer里面一般用的dk比较大512。所以除以dk是一个不错的选择。图讲述了计算过程mask主要避免在t时间看到以后时间的东西，对于qt和kt之后的计算那些值，给换成一个非常大的负数，再进入softmax做指数的时候，会变成0。导致出来的这些对应的权重都会变成0，只会前面的那些值出效果。mask效果是在训练的时候让t个时间的query只看对应的前面那些的key value pair。使得在做预测的时候能够一一对应上。

### Multi-Head Attention

这里说与其做一个单个的注意力函数，不如把整个query，key value投影到一个低维，投影h次，再做h次的注意力函数，每一个函数的输出把它并在一起，然后再投影出来会得到最终的输出。看图， v k q进入一个线性层之后 做h次Scaled Dot-Product Attention 合并在一起最后做一次线性的投影，会回到我们的Multi-Head Attention。。为什么要做多头注意力机制呢？参数是不同的Linear学的。跟cnn里面的多个卷积核有异曲同工之妙，1个可能抽取特征不完善，就多个一起干活。有多个输出通道的感觉，每个head相当于一个专家，可以从不同的角度找相似。（这里介绍多头的公式，每个参数代表含义）论文里用的8个头。注意力因为有残差连接的存在使得输入和输出的维度至少是一样的，做法是说投影的时候，投影的是输出的维度512 / 8 每一次投影到一个4维在上面算注意力函数，并且再投影回来。

### Transformer里面如何使用注意力

三种使用情况，看架构图，三种不一样的注意力层。

编码器注意力：编码器的输入，假设句子长度是n，其实输入是一个n个长为d的向量。看到注意力层有三个输入，分别表示的是key value 和 query（一根线，复制成了三下）意思是同样一个东西既作为key也作为value也作为query，叫做自注意力机制，说kvq其实是一个东西就是自己版本身。输入了n个query，每个query会拿到一个输出，意味着会有n个输出，输出和value长度是一样的，那么输出的维度也是d，意味着输入和输出的大小是一个东西。线性变换？输出其实是value的一个加权和权重来自于query和key的一些东西，本身是一个东西。（但是Wq Wk Wv不同）。输出其实就是输入的一个加权和，权重来自于自己本身跟各个向量的一个相似度。如果有多头的话因为有投影，在这个地方会学习h个不一样的距离空间出来，使得出来的东西是会有一点点不一样。这里是第一个注意力层是如何用的。

解码器：同样的一变三，输入是一样的知识长度可能变成了m维度也一样的，唯一不一样的是有个Masked,后面的东西要设成零

第三个地方的注意力：key和value来自于编码器的输出 query来自于解码器下一个attention的输入。编码器最后一层的输出n个长为d的向量解码器的masked attention是m个长为d的向量。编码器的输出作为value和key进来，解码器下一层的输出作为query进来，意味着是说对解码器的每一个输出作为query我要算一个我要的输出(来自value的一个加权和，来自于编码器的输出的加权和)这个attention做的事情就是去有效的把编码器里面的一些输出根据我想要的东西拎出来。意味着根据在解码器的时候输入的不一样根据当前的那一个向量去在编码器的输出里面去挑我感兴趣的东西，注意到你感兴趣的东西。attention是如何在编码器和解码器之间传递信息的时候起到的一个作用。

### feed-forward

就是一个MLP。输入的序列有很多个词，每个词就是一个点就是一个position，把一个MLP对每一个词作用一次，每个词作用的是同样的要给MLP。MLP知识作用在最后一个维度。FFN(x)公式 线性层 Relu的激活层 再有一个线性层。单隐藏层的MLP(不了解)，中间隐藏层输入扩大四倍最后输出的时候回到输入的大小。PyTorch来实现就是两个线性层放在一起，不需要改任何参数，当输入是是一个3d的时候默认最后一个维度做计算。attention起到的作用把整个序列里面的信息抓取出来，做一次汇聚aggregation，所以MLP可以单独做。最后加工成我最后要的那个语义空间向量的过程。

对比看RNN如何做的 一些序列 加上线性层 上一个时刻的输出放回来作为输入一起并入进去，完成一个信息的传递。都是用一个线性层来做一个语义空间的转换。不一样的是如何传递序列的信息。主要就是如何有效的去使用序列的信息。
